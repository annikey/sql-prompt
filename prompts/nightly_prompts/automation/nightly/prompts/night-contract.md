# Ночной контракт

Работаешь с одной задачей, указанной в Run parameters. Не выбирай следующую:
очередью и новыми сессиями управляет внешний PowerShell-скрипт.

1. Прочитай переданные проектные инструкции и документ текущего тикета. Для анализа читай только относящиеся к нему файлы. Не загружай весь репозиторий или историю переписки.
2. Изменяй только разрешённые пути и только в рамках текущего тикета. Посторонние незакоммиченные изменения могут принадлежать предыдущей задаче этой ночи: не откатывай и не переписывай их.
3. Не изменяй очередь, AGENTS.md, правила/конфигурацию агента, проверочный скрипт, секреты, CI или Git. Не выполняй commit, push, merge, reset, переключение веток и установку зависимостей.
4. Shell-команды, MCP, браузер, подагенты и интерактивные вопросы в этом режиме запрещены. Не пытайся обойти отказ инструмента. Внешний скрипт запустит согласованные проверки после твоего завершения.
5. Если нужно отсутствующее разрешение, непредусмотренное архитектурное решение, доступ к внешней системе или расширение задачи — зафиксируй конкретный блокер и остановись. Не жди ответа ночью.
6. Обновляй документ тикета после существенных решений, а не только перед выходом. Отделяй предположения от найденных фактов и результаты проверок от ожиданий. Не пиши, что тесты прошли, если их не запускал. В этом режиме напиши «ожидают запуска обвязкой».
7. Не ставь чекбоксы всей задачи и не добавляй маркер согласования плана. Ты готовишь результат для человека, а не принимаешь собственную работу.

## Машинный результат

Перед завершением запиши новый JSON-файл по точному resultFile из Run parameters:

```json
{
  "ticketId": "ID-ИЗ-RUN-PARAMETERS",
  "status": "completed",
  "summary": "Что подготовлено и что осталось проверить",
  "changedFiles": ["относительный/путь"],
  "blockers": []
}
```

status — только completed или blocked. completed означает, что твоя часть закончена,
а не что тикет принят или тесты успешны. При blocked перечисли причины.
Если записать результат невозможно — объясни это в финальном ответе; обвязка остановит прогон.
