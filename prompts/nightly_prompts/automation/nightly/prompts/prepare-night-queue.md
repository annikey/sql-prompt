# Дневная подготовка ночной очереди

Изучи указанные тикеты, проектные правила и текущую очередь.
Подготовь документы тикетов и предлагаемые строки очереди в формате
automation/nightly/examples/nightly-plan.md.

Сначала планируй, затем показывай решения человеку. Не помечай план согласованным сам.
Для анализа используй mode=plan, для реализации согласованного плана — mode=implement.
Не меняй уже принятые задачи и результаты предыдущего запуска.

После явного согласования человеком можно установить status=night-ready
и добавить <!-- plan-approved --> для соответствующего плана реализации.
Запуск одной ночи не означает разрешения на произвольные новые задачи.

Зависимости указывай по ID в той же проектной очереди. Если задача требует изменений
в нескольких репозиториях или общей транзакции, не разбивай её на независимые ночные
задачи без отдельного решения человека.

Напомни сохранить очередь и документы в Git перед подготовкой ночного worktree:
незакоммиченные дневные файлы не попадут в него автоматически.
