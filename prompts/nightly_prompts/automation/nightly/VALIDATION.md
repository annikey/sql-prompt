# Проверка пакета

## Что проверено при сборке

- 65 статических проверок: кодировки, комплектность, ссылки между документами,
  соответствие примера очереди регулярному выражению в PowerShell,
  отсутствие согласования в пустом шаблоне тикета,
  предохранители запуска, отдельные сессии, блокировка shell и отсутствие
  автоматической приёмки собственных изменений.
- Примеры JSON прочитаны парсером; архив проверен на целостность.
- PowerShell-файлы содержат только ASCII, а русские промпты/документы читаются
  явно как UTF-8: это не требует менять системную кодовую страницу Windows.

## Что не проверено здесь

В этой среде нет Windows PowerShell, планировщика Windows и корпоративного OpenCode.
Не выполнены PowerShell-парсинг реальным движком, живой запуск агента,
проверка прав инструментов корпоративной сборки, авторизация, тесты ваших проектов,
расписание с отключённым RDP и провайдерский учёт токенов.
Статическая проверка не заменяет эти испытания.

## Обязательная проверка на Windows

1. tests/Test-Queue.ps1 — синтаксический разбор всех PS-файлов движком PowerShell;
   порядок задач, зависимости, циклы, неверные ID/чекбоксы, статусы, пути.
2. tests/Test-Worker.ps1 — отдельный процесс-заглушка, ненулевой код возврата,
   таймаут и STOP-файл. Без модели и внешнего сервиса.
3. Test-NightlySetup.ps1 — реальные пути, CLI help, очередь и worktree.
4. Invoke-Nightly -DryRun — проверка выбора задач без выполнения.
5. Invoke-Nightly -Manual — одна маленькая планирующая задача.
6. Одна реализация с настоящим локальным verifier; затем проверка расписания.

Если любой этап падает, не включайте расписание и не ослабляйте корпоративные
политики ради обхода ошибки. Сохраните точный вывод для исправления.
