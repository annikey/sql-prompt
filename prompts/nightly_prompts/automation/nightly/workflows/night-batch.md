# Опциональный ночной прогон

Общая механика хранится в ai-fosql, проектные требования и очередь — в своём репозитории.

1. Днём: prepare-night-queue → plan-ticket → человеческое согласование.
2. Вечером: сохранить подготовку в Git и подготовить отдельный worktree.
3. Проверить Test-NightlySetup и Invoke-Nightly -DryRun.
4. Планировщик вызывает Invoke-Nightly с локальной конфигурацией.
5. Скрипт по очереди выбирает night-ready задачи, передаёт night-contract
   и plan-ticket/implement-ticket в новую сессию OpenCode.
6. Скрипт проверяет результат, запускает проектный verifier для реализации,
   сохраняет журнал и ready-for-review. На блокере/ошибке останавливает весь прогон.
7. Утром: review-night-run, приёмка человеком, ручной перенос результатов в дневную ветку.

Этот workflow не является автоматически подключаемым skill.
Он не требует изменения глобальных правил Kilo/OpenCode или всех общих skills.
